# ACAS Science 题目分析站

本地运行的 Python + MkDocs Material 文档站点。每道题对应一个 Markdown 文件，原题以扫描页图像展示，点击图片可打开高清原图；分析写在同一文件中。支持搜索、目录跳转及上一题/下一题导航。

## 初始化

在 `exam-site` 目录运行：

```sh
/opt/homebrew/bin/python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python scripts/prepare_questions.py
```

脚本从上一级目录读取 `科学.pdf`，将每页渲染到 `docs/assets/source-pages/`，并创建 40 个题目 Markdown 文件。第 38 题引用 PDF 第 38、39 页。已存在的 Markdown 不会被覆盖，可安全重跑以补齐原题图片。

## 局域网访问

先构建静态站点：

```sh
mkdocs build --strict
```

再启动提供网站和共享笔迹接口的服务器：

```sh
python scripts/annotation_server.py --bind 0.0.0.0 --port 8000
```

本机可打开 <http://127.0.0.1:8000>；同一局域网设备访问 <http://192.168.3.11:8000>。如果 macOS 防火墙询问是否允许 Python 接收入站连接，请允许；不要在路由器上配置公网端口转发。

编辑 Markdown 后，重新运行 `mkdocs build --strict` 即可更新网站文件；运行中的服务器会直接提供新文件。旧的 `python -m http.server` 或 `mkdocs serve` 不提供笔迹同步接口，必须改用上面的启动命令。若 8000 端口被占用，请先停止原服务器，或用 `--port 8001` 并访问新端口。

## 共享画笔

每个页面底部的浮动工具栏提供浏览、画笔、橡皮、颜色、粗细、撤销、清空和整页全屏工具，支持鼠标、触摸和手写笔。画笔覆盖全页面，包括原题图片、分析文字、公式、知识图和导航区域，不仅限于题目。点击浏览按钮或按 Escape 可恢复触摸滚动和链接操作；电脑在画笔模式下仍可用滚轮滚动。橡皮只擦除标注，不改变原内容；撤销只撤销当前页面会话中自己的上一笔。清空需确认，并对所有设备的当前页面生效。

打开同一页面的设备每秒从同一个后端获取最新笔迹；笔迹按页面地址分开存储，首页、知识体系图和每道题均可独立标注。完成一笔后自动保存，其他设备通常在约 1 秒内看到。尚未完成的笔画不广播。笔迹以起笔处的图片或内容块为锚点，滚动时跟随原内容。不同屏幕宽度下按内容块比例缩放，但文字换行后不能保证逐字精确对齐；跨多个内容块的长笔画也会受到重新排版影响。修改文档结构后，旧笔迹可能需要清空重画。

笔迹保存到 `data/annotations.sqlite3`，重启服务器或重新构建站点不会丢失。备份时保留这个数据库；不要删除 `data/`。数据目录不在静态网站内，也不会提交到 Git。可通过 `--data /path/to/annotations.sqlite3` 指定其他位置。

短暂断线时未发送操作会保存在当前浏览器，重新连接后自动发送；若浏览器禁用或耗尽本地存储，请保持页面打开直到显示已同步。另一台设备清空后，旧的离线笔迹不会重新上传。若清空时其他设备刚更新笔迹，后端拒绝这次清空并提示重新操作，以防误删。

这是可信局域网内的共享白板，没有账号或编辑权限隔离，任何可访问服务器的设备都能画画和清空。不要暴露到公网。只在本机使用时省略 `--bind 0.0.0.0`，默认绑定 `127.0.0.1`。

运行后端测试：

```sh
.venv/bin/python -m unittest discover -s tests -v
```

## 编辑分析

编辑 `docs/questions/qNN.md` 中的 `## 分析` 部分。`mkdocs.yml` 中的题目目录顺序决定上一题/下一题顺序。生成的网站位于 `site/`，运行 `mkdocs build --strict` 可检查页面及资源链接。
